# AUTOINSTALL OS METHOD

## 1. Idea
The idea of auto install these OS are based on the term "ISO Customized", which means we have to make changes in the structure of the ISO file. Following these steps:
- Create a file call "Answer file". They have differents names depending on the OS, but functioning the same way. This file will be our predefined configuration for the OS.
- Extract the original ISO file.
- Add needed file such as customized scripts, data used for config, ... and Answer file (required).
- Repack into a new ISO File.
